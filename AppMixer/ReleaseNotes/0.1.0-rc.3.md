**QEQ — Quick EQ. Per-app mixer and equalizer for macOS.**

- New QEQ name and slider-tile app icon; existing saved app settings are preserved.
- The menu bar panel fits its contents, up to 720 points or the available screen height. Long lists scroll.
- Bass/EQ boosts raise the selected frequencies without a matching full-band cut. Sample-peak protection acts only on overload, with a live gain-reduction indicator and no added playback buffering.
- Saved idle apps wait for playback before creating routes. Paused apps release their routes, and apps playing on other outputs are identified.
- A stalled route no longer shuts down every app. One automatic reconnect is attempted; persistent failures stay bypassed per app until Retry or a playback/process/output change.
- Footer menu → Copy diagnostics reports device and callback state without recording audio.
- Shorter README with native-interface screenshots and a separate development guide.

macOS 14.4+, Apple Silicon and Intel. Both app and DMG are Developer ID signed, notarized, and stapled.

Quit AppMixer/QEQ before replacing it with QEQ.app. Every launch starts bypassed. For the reported USB issue, test with both a saved idle app and a playing app, then pause/resume and reconnect the device. The restored-idle-app and failure-isolation regressions are covered by tests; the specific remote USB hardware has not been directly tested. If a route still fails, use Copy diagnostics and include the result with the report.
