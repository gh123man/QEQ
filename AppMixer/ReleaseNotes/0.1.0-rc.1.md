First internal release candidate for macOS 14.4+, with Apple Silicon and Intel support.

- Menu bar controls for per-app volume, mute, and processing bypass.
- Five-band parametric EQ with draggable response graph, exact controls, presets, and live output spectrum.
- Audio-focused app list with Chrome/helper grouping and parent app icons.
- Global bypass restores the original system audio paths; every launch starts bypassed.
- Public Core Audio taps, no installed driver, and only system-audio capture permission.

This RC is signed with an Apple Development certificate and hardened runtime. It is **not notarized** and is intended for internal testing on the development Mac; it is not a Gatekeeper-ready distribution release. No signing key is included in the repository or artifacts.

Download the ZIP or DMG, quit the existing mixer, and open AppMixer. Click the sliders icon in the menu bar, start playback, adjust an app, and enable processing. macOS may ask for system-audio permission again. See the README listening checklist for isolation, bypass, device changes, and latency checks.

The live spectrum runs while an EQ panel is open and that app is being processed. Flat/bypassed apps are not intercepted solely for visualization. Bluetooth/device buffering still contributes latency; the footer reports hardware buffer duration, not measured end-to-end delay.

SHA256SUMS and release-manifest.json accompany the build and identify its source commit and signature.
