**QEQ — Quick EQ. Per-app mixer and equalizer for macOS.**

- Global and per-app five-band parametric EQ with 11 presets and live spectra.
- Independent app volume, quick mute, and per-app bypass.
- One switch to restore system audio.
- App exclusions, optional launch at login, and quiet update checks.
- Consistent translucent panel tint when opening and changing focus.

Requires macOS 14.4 or newer. Supports Apple Silicon and Intel.

Install by dragging QEQ from the DMG to Applications. Existing RC users can update from Settings → Check now → Install update; release-candidate opt-in is not required for 1.0.0.
