**QEQ — Quick EQ. Per-app mixer and equalizer for macOS.**

- Global EQ shares each app's realtime callback, with independent bypass and no added playback buffer.
- A full-width global spectrum stays visible above a pinned search field. App rows scroll below it.
- Layered app spectra, collapsed-row output meters, and prominent quick-mute buttons show which apps are making sound.
- Opening the panel starts analysis even with flat EQ. Global bypass releases all audio taps.
- Improved bass-frequency resolution and removed spectrum peak hold that concealed cuts. EQ gain and output-level axes are labeled separately.
- Eleven presets, system accent color, double-click band reset, a subtler global response line, and a power-icon Quit button.
- Gain controls explain that −18 dB leaves about 13% amplitude; the clipping-protection indicator appears only while limiting.
- README screenshots now include clearly labeled simulated spectra. Release preparation refreshes screenshots; CI checks their source fingerprints and the release workflow renders and attaches a screenshot ZIP.

macOS 14.4+, Apple Silicon and Intel. App and DMG are Developer ID signed, notarized, and stapled.

Quit QEQ before replacing the app. Saved app/global EQ settings are retained; each launch starts bypassed. Enable Mixer for live analysis and processing. The 16,384-sample spectrum window covers about 341 ms at 48 kHz; it affects visual settling only, not playback buffering. The global spectrum overlays app spectra, not a phase-aligned measurement of the final system mix. Use the footer menu's Copy diagnostics if a route fails.
