**QEQ — Quick EQ. Per-app mixer and equalizer for macOS.**

- Right-click an app to exclude it from the mixer. Restore it from Settings → Excluded Apps.
- PowerChime is excluded by default. Excluded apps use normal system audio; saved EQ settings are retained.
- Fix update installation from local builds and add Install update beside Check now.
- Move Copy diagnostics into Settings and simplify the main menu.

macOS 14.4+, Apple Silicon and Intel. To update from RC.7, enable Include release candidates in Settings and click Check now, then Install update (or Update available in RC.7).
