**QEQ — Quick EQ. Per-app mixer and equalizer for macOS.**

- Lower idle CPU usage and faster spectrum analysis during playback.
- An Update available button, with installation only when you choose. Release candidates are opt-in.
- Settings for update checks, log levels, and saving diagnostic logs.
- Start with macOS, enabled by default and configurable in Settings.

macOS 14.4+, Apple Silicon and Intel. Install this release manually once to get the updater. Quit QEQ before replacing the app; saved settings are retained.
